✓ Homebrew 安装完成

接下来，打开 Codex Co²

共享一条 Codex 会话，一起推进工作。

应用已放入「应用程序」，无需再次拖拽安装。

  1. 先尝试打开应用

    按 ⌘ 空格，搜索 Codex Co² 并回车；也可以在 Finder 的「应用程序」中双击它。

    如果正常打开，直接继续第 3 步。

  2. 如果 macOS 提示无法打开

    在拦截提示中点击「完成」，打开下方设置页，向下找到「安全性」，在 Codex Co² 的说明旁点击「仍要打开」，再按系统提示验证并确认打开。

    打开隐私与安全性

    浏览器可能询问是否允许打开“系统设置”。若按钮无效，请手动前往「系统设置 → 隐私与安全性」。未显示「仍要打开」时，请先重试第 1 步。

  3. 连接你的 Codex Desktop

    保持官方 Codex Desktop 运行，再打开 Codex Co²，检查显示名称，选择要共享的会话并生成邀请。

此实验预览版采用临时签名，尚未经过 Apple 公证。只有在你确认来源可信时，才为此应用放行。系统的「仍要打开」和身份验证需要由你亲自完成。查看 Apple 官方说明

以后更新前，先停止共享，并从 Co² 菜单栏退出应用。
